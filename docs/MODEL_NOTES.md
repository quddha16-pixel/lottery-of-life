# Current model scope

The current review branch extends the original Phase 1 foundation. Its authoritative scope and limitations are documented in:

- [Historical sampling, geographic compatibility, evidence and date conventions](HISTORICAL_MODEL.md)
- [Living-world rules, save migration, limitations and continuation plan](LIVING_WORLD.md)
- [Asset credits and licenses](ASSET_CREDITS.md)

All ten founding species remain unlocked. Three extra species remain available through the earned-Coin pack. Daily phases, resource needs, persistent injuries, permanent death, lifetime rewards, sampled offspring, modest inheritance, bloodline continuation, journals, collection and JSON save management remain functional.

Lifespans, development thresholds, care, phase costs, survival hazards and species success scores are provisional gameplay values informed by natural history, not calibrated scientific predictions. Passing software tests establishes behavior and integrity, not scientific accuracy. Sterile workers can succeed through colony contribution; reproduction is not mandatory. Adult behavior is gated by species stage, and dependent newborns do not receive independent hunting or movement abilities.

The common octopus retains a terminal breeding episode. High-fecundity taxa track a sampled cohort, not an implausibly tiny full clutch. Reproductive delays abstract gestation or incubation, and male-controlled breeding tracks the partner's cohort. These mechanics need more detailed biological review.

No real-money purchases, paid services or external AI are used. Pack rarity is a collection attribute, not conservation status. The field pack still draws one card with configured probabilities: red fox 60%, European robin 30%, harbor seal 10%; duplicates return 20 of the 60 earned Coins spent. Seeded randomness is reproducible, not cryptographic. Browser saves can be edited or rolled back; there is no server-enforced anti-cheat.

Taxonomy, distribution and life-history reference starting points include [Animal Diversity Web](https://animaldiversity.org/), [IUCN Red List](https://www.iucnredlist.org/), [AmphibiaWeb](https://amphibiaweb.org/) and the species accounts linked from the field guides. Current historical windows and ecosystem coefficients are explicitly approximate and require expert/content review.
